# 해솔국 이야기

2000년대 초 국산 온라인 RPG의 감성을 살려 새로 만든 2D 탑다운 RPG입니다. (지금은 혼자 하는 게임, 나중에 서버를 붙일 수 있게 규칙을 나눠 둠)
불타 버린 마을에서 해솔성으로 흘러든 뜨내기가 되어, 성을 위협하는 흑풍단과 검은 안개의 비밀을 쫓습니다.

▶ 바로 하기: https://minhyuk94.github.io/haesol/

## 들어 있는 것 (1막)

- 캐릭터 만들기: 이름·성별·머리 모양·머리 색 (몸·옷·머리·무기 층을 겹쳐 그림)
- 백성으로 시작해 레벨 5에 수련관에서 직업 선택: **검사·자객·술사·도인** (직업마다 기술 셋)
- 칸 단위 이동과 공격, 단축칸(1~8) 기술·물건, 대상 고르기(Tab)
- 가방·장비·능력치·기술·퀘스트 창, 주막·대장간·포목점 사고팔기
- 지도 여섯: 해솔성, 솔내들, 안개숲, 멧쥐굴 1·2층, 흑풍단 소굴 / 몬스터 10종과 대왕 둘
- 이야기 퀘스트 여덟 개 (성문장·주막집 하나·떠돌이 무사 무진…), 대화창 얼굴 그림
- 아래 고정 패널: 글창(알림), 체력·기력·경험치, 지명·좌표 표시

## 조작

| 키 | 하는 일 |
| --- | --- |
| 방향키 / WASD | 한 칸씩 걷기 |
| 스페이스 / Z | 앞 칸 공격 (누르고 있으면 계속) |
| Enter / X | 말 걸기, 대화 넘기기 |
| 1 ~ 8 | 단축칸 (기술·물건) |
| Tab | 가까운 적 고르기 (술법 대상) |
| I · C · K · Q | 가방 · 능력치 · 기술 · 퀘스트 |
| Esc | 메뉴 (저장·소리) |

## 어떻게 만들었나

- Godot 4.6 (GDScript), 웹으로 내보내 GitHub Pages
- 그림·소리·지도는 모두 코드로: `tools/art`(팔레트·절차적 그리기·Scale2x로 키운 소품·종이 인형식 캐릭터 층), `tools/sound`(신스 브라스·베이스·드럼 합성), `tools/maps`
- 규칙은 `scripts/core/rules.gd`(능력치·피해·경험치·가방·상점·퀘스트), 데이터는 `data/*.json`
- 테스트 `tests/run_tests.gd`: 규칙, 데이터끼리 맞는지, 모든 지도에서 사람·출구·대왕에 걸어서 닿는지
- 글꼴: [갈무리](https://github.com/quiple/galmuri) (SIL OFL 1.1)
